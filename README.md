# SpringBoot-student-management
Spring Boot Student Management System is a RESTful web application developed using Java and Spring Boot. The project demonstrates core backend concepts such as CRUD operations, REST API design, data validation, and global exception handling following industry best practices.


✨ Key Features

Create, update, delete, and retrieve student records

Search students by name keyword

Input validation using Jakarta Bean Validation

Global exception handling with custom exceptions

RESTful API design

Clean layered architecture

🛠️ Tech Stack

Java

Spring Boot

Spring Data JPA

Hibernate

Postgres-Database

Lombok

Maven
